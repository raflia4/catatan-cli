# Aplikasi Catatan CLI

Aplikasi catatan sederhana berbasis terminal, dibuat dengan Python.

## Fitur
- Tambah, lihat, dan hapus catatan
- Data tersimpan otomatis ke file JSON
- Validasi input (catatan kosong, nomor tidak valid)
- Penanganan file JSON rusak (file diamankan sebagai `catatan_rusak.json`)

## Cara Menjalankan
1. Pastikan Python 3 sudah terpasang
2. Jalankan: `python catatan.py`

## Yang Dipelajari
Fungsi, list, loop, baca-tulis file JSON, `try/except`, dan penanganan error.
